# Training

Keep reusable curriculum definitions or small generators here.

Generated/local training material belongs under `generated/` or `local/`; both are ignored by Git. Large datasets should be stored as external artifacts rather than committed into the product repository.

Before designing training credit or validators, read [`docs/TRAINING_BASELINE.md`](../../docs/TRAINING_BASELINE.md). It is a developer/evaluator reference for preserving proof, evidence, action, outcome, context, and actual-experience separation. It is not agent training data or a universal curriculum.
